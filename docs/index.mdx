# Fetcher

`@ilokesto/fetcher` is a small OpenAPI-aware wrapper around the real `ky` runtime. It keeps `ky.create`, `extend`, hooks, `prefixUrl`, custom `fetch`, lazy `ResponsePromise` parsing, and `ky` errors, then adds typed route templates, grouped shortcut requests, inferred `.json()` results, and a non-throwing `safe` surface.

It does not generate OpenAPI types, add caching, or replace `ky`'s transport behavior. Generate or write a compatible `paths` type, then use Fetcher where you want that contract applied to `ky` calls.

## Installation

Fetcher releases are published on the `beta` dist-tag. Install the selected beta-channel release together with its `ky` peer dependency.

```package-install
@ilokesto/fetcher@beta ky
```

The package is published as a dist-based ESM package and currently targets Node.js 22 or newer for package tooling. Runtime behavior is delegated to `ky`, so browser, server, and test usage follow the same constraints as your chosen `ky` environment.

## Quick example

```ts lineNumbers
import { createFetcher } from '@ilokesto/fetcher/openapi';
import type { paths } from './__generated__/openapi';

const api = createFetcher<paths>({ prefixUrl: '/api' });

const user = await api
  .get('/users/{id}', {
    params: {
      path: { id: '42' },
      query: { include: 'profile' },
    },
  })
  .json();
```

The request is sent to `/api/users/42?include=profile`, and `user` is inferred from that operation's preferred JSON response. The [quick start](/en/fetcher/quick-start) provides a complete runnable file without requiring generated types.
